Call quality
?
Percentage of one-minute windows that would have sustained a clean video call. A minute counts as bad if it overlaps a detected outage, TCP packet loss exceeds 1%, latency was sustained-high (median RTT > 200 ms, or 3+ probes above 300 ms), or jitter (IQR of RTT) exceeds 75 ms. Thresholds follow ITU/Cisco interactive-video guidance, with sustained-slow latency required so a single jitter-buffer-absorbed spike doesn't flag a minute.

One-minute windows where call quality fell below threshold without a connectivity outage — high latency, jitter, or TCP loss. The line stayed up, but a call would have been audibly rough during these minutes.
